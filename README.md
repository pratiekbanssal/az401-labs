# AZ-401 Labs

Hands-on labs for **AZ-401: Designing and Implementing Microsoft Agentic DevOps Solutions**.

Each lab is self-contained. Open its folder and follow the README from top to bottom.

| Lab | What you build |
| --- | --- |
| [Lab 1: Azure DevOps MCP Server](lab-01-azure-devops-mcp-server/) | Connect GitHub Copilot to Azure DevOps with MCP, ask about work items, code and wiki pages in plain English, and control exactly what the AI may change |

More labs are on the way.

## How to use this repo

```bash
git clone https://github.com/pratiekbanssal/az401-labs.git
cd az401-labs/lab-01-azure-devops-mcp-server
```

Then follow that lab's README. Every lab ends with a clean-up step, so you don't leave anything running.

## Diagrams

Each lab has a `diagrams/` folder with `.svg` images (shown in the README) and `.excalidraw` sources. To edit a diagram, open [excalidraw.com](https://excalidraw.com) and drag the `.excalidraw` file onto the page.
